# 完整命盘报告输出模板

## 报告结构

生成命盘报告时，严格按照以下结构输出：

---

### 一、基本信息

| 项目 | 内容 |
|------|------|
| 阳历 | YYYY年M月D日 |
| 农历 | 二〇〇二年七月十七 |
| 干支纪年 | 壬午年 戊申月 乙丑日 丁丑时 |
| 时辰 | 丑时（01:00~03:00） |
| 性别 | 男（阳男）/ 女（阴女） |
| 生肖 | 马 |
| 星座 | 处女座 |
| 命宫地支 | 未 |
| 身宫地支 | 酉 |
| 命主 | 武曲 |
| 身主 | 火星 |
| 五行局 | 水二局 |

附五行局推算过程。

### 二、十二宫排盘总表

完整12宫表格，包含：宫名、天干地支、主星（含亮度与四化）、辅星、杂耀、长生12神、博士12神、大限范围、是否身宫/来因宫。

### 三、生年四化表

四化星曜及所在宫位，附含义解读。

### 四、各宫位详析

每个宫位包含：
1. 主星特质与亮度解读
2. 辅星影响
3. 杂耀影响
4. 四化影响（生年四化+宫干飞化）
5. 三方四正综合
6. 长生12神暗示
7. 健康提示（疾厄宫及相关宫位）

### 五、格局分析

逐一列出识别到的格局，包含：
- 格局名称与等级（excellent/good/neutral/caution）
- 必须条件、加分项、破格条件
- 古籍出处
- 综合解读

### 六、大限运势详析

每个大限包含：
1. 大限宫位主星及亮度
2. 大限主题与关键事件
3. 吉凶判断

### 七、流年运势

至少给出近5~7年的流年分析：
1. 流年干支与四化
2. 流年关键提示
3. 流年与命盘的交互

### 八、六冲关系分析

### 九、星耀亮度总览

14主星的亮度及解读。

### 十、健康总览

各宫地支对应的健康提示。

### 十一、综合人生建议

事业、财运、婚姻、健康、人际、外出、精神等维度。

---

## 输出规范

1. 所有解读必须基于排盘结果，不可凭空臆断
2. 亮度等级：庙>旺>得>利>平>不>陷（iztro七级）或 bright>normal>dim（倪师三级）
3. 化忌入何宫，该宫位即为人生课题，需重点提示
4. 武曲/廉贞/七杀/破军在夫妻宫一律建议晚婚
5. 看婚姻必须同时看福德宫
6. 不确定的内容标注"无法确定"，不编造
