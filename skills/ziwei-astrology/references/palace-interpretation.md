## 解读原则

1. 亮度优先：庙旺正面特质强，陷落负面特质强
2. 四化为重：化禄增益，化权掌控，化科名声，化忌阻碍
3. 三方四正：解读任何宫位必须结合三方四正综合判断
4. 空宫借星：无主星时借对宫，力量减半
5. 身宫叠加：身宫所在宫位意义加倍重要
6. 来因宫：代表此生因果来源

## 辅星核心特质

**六吉星**：左辅/右弼（贵人助力）、文昌/文曲（文才学术）、天魁/天钺（贵人机遇）

**六煞星**：擎羊（刑伤刚烈）、陀罗（拖延纠缠）、火星（急躁暴烈）、铃星（阴火闷烧）、地空（虚耗空想）、地劫（劫夺破财）

**禄存**：财星、稳定收入、守财
**天马**：迁移、奔波、变动

## 各宫解读维度

每个宫位必须从以下维度解读：
1. 主星特质与亮度
2. 辅星影响（吉星增吉，煞星增凶）
3. 杂耀影响
4. 四化影响（生年四化+宫干飞化）
5. 三方四正综合
6. 长生12神暗示
7. 六冲关系
8. 大限走势

### 四化在夫妻宫

| 四化 | 断语 |
|------|------|
| 化禄 | 与配偶有先天缘分，配偶越来越会赚钱 |
| 化权 | 婚姻多为主动争取而来，配偶掌握决策权 |
| 化科 | 能与配偶和谐相处，配偶有名声或专业技能 |
| 化忌 | 欠下婚姻债务，早婚早离，建议晚婚或不婚 |

### 婚姻判断核心（倪师）

**"看婚姻，光看夫妻宫，大错特错，一定要同时看福德宫。"**

- 夫妻宫：看配偶的星性、外形、性格、互动模式
- 福德宫：代表夫妻深层感情、婚姻能否长久
